# README

## アプリケーション名

FinTrack

## アプリケーション概要

個人向けの家計管理 Web アプリケーションです。銀行口座・クレジットカードの取引明細 CSV を取り込み、収支の分類・資産管理・カード引き落とし照合を行います。

- 銀行・カード明細 CSV の取込（複数金融機関対応）
- 収入・支出の一覧表示とカテゴリ付与
- 資産カテゴリ別の残高管理
- 収入・支出の資産カテゴリへの分割（単一カテゴリ / 手動 / パターン）
- カード引き落としと銀行明細の照合・差異管理

が可能です。

## 目指した課題解決・開発背景

個人の家計管理では、複数の銀行口座やクレジットカードを使うことが多く、各金融機関が異なる形式の CSV を提供するため、取引データの集約や分類に手間がかかります。また、カード利用明細と銀行口座からの引き落とし金額が一致しないケースもあり、手作業での照合作業が発生しやすくなります。

既存の家計簿アプリは機能が多く、必要な操作だけをシンプルに行いたいというニーズに応えきれない場合もあります。

これらの課題を解決するために開発したのが FinTrack です。

金融機関ごとの CSV パーサーを実装し、取引データを一元的に取り込めるようにしました。摘要パターンに基づく自動カテゴリ付与や分割パターンにより、分類・分配作業を効率化しています。カード引き落とし照合機能により、明細と実際の引き落としの差異も管理できます。

## 利用方法

アカウント作成が必須となります。アカウント作成後、ログインし、カテゴリ設定 → CSV 取込 → 分類・分割 → 資産確認の順に操作を行ってください。

## 実装機能

### ユーザー管理機能

FinTrack の利用者を管理する機能です。Spring Security によるフォームログイン・ユーザー登録（BCrypt ハッシュ）を提供します。

### CSV 取込機能

銀行・カード会社の取引明細 CSV をインポートする機能です。楽天銀行・みずほ銀行・三菱 UFJ 銀行・楽天カード・楽天デビットに対応し、取込履歴の参照と再取込時の更新差分管理も行えます。fingerprint による重複排除により、同一 CSV の再取込でもデータが重複しません。

### 収支管理機能

銀行・カード取引を統合して収入・支出の一覧表示と詳細確認ができる機能です。個別または一括でのカテゴリ付与、摘要パターンに基づく自動カテゴリ付与ルールの登録に対応しています。

### 資産管理機能

資産カテゴリごとの残高を管理する機能です。未分類の取引を一覧表示し、カテゴリ設定の漏れを確認できます。

### 収支分割機能

収入・支出を資産カテゴリへ分配する機能です。全額を 1 カテゴリに割り当てる単一分配、割合または金額を指定する分割パターン、手動での金額指定の 3 方式に対応しています。

### カテゴリ・分割パターン管理機能

資産カテゴリ・支出カテゴリ、および収入・支出それぞれの分割パターンを登録・編集・削除できる機能です。

### カード引き落とし照合機能

月別のカード明細と銀行口座からの引き落としを照合し、差異の確認・解消を行う機能です。

## サーバー構成

FinTrack を公開・運用するため、AWS 上に以下の構成でサーバー環境を構築しています。

### 構成概要

| 項目 | 内容 |
|---|---|
| クラウド | AWS |
| OS | Amazon Linux 2023 |
| ネットワーク | パブリックサブネット 1 つ |
| サーバー | EC2 インスタンス 1 台（アプリ・DB・リバースプロキシを同居） |

単一 EC2 に Spring Boot アプリケーション、PostgreSQL、nginx、Fail2ban を配置するシンプルな構成とし、小規模な個人利用に必要十分な可用性・運用性を確保しています。

### ソフトウェア構成

```
[ クライアント ]
      │
      ▼  HTTPS (443) / HTTP (80)
[ nginx ] ── リバースプロキシ・TLS 終端
      │
      ▼
[ Spring Boot アプリ ]
      │
      ▼  localhost のみ
[ PostgreSQL ]
```

- **nginx**: 外部からの HTTP/HTTPS リクエストを受け付け、Spring Boot アプリへプロキシ
- **Fail2ban**: 不正なログイン試行などに対する自動ブロック

### セキュリティ設定

| ポート | 用途 | 公開範囲 |
|---|---|---|
| 443 | HTTPS | インターネット全体 |
| 80 | HTTP（HTTPS へリダイレクト） | インターネット全体 |
| 22 | SSH（管理用） | 管理者 IP のみ |
| 5432 | PostgreSQL | **非公開**（セキュリティグループで閉鎖） |

- PostgreSQL は `localhost` からのみ接続可能とする設定とし、外部から DB へ直接アクセスできないようにしています
- DB 接続情報などの機密値は環境変数で管理し、ソースコードには含めていません
- アプリケーション認証は Spring Security（BCrypt）により実装しています
